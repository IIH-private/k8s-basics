# Kubernetes Learning Portfolio

This repository documents my practical Kubernetes learning journey and structured preparation for the Certified Kubernetes Application Developer (CKAD) certification.

The focus is on hands-on labs, reusable Kubernetes manifests, troubleshooting, and real-world application deployment.
